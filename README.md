# ML Soluciones Web

Landing en React y Vite.

## Desarrollo local

```sh
npm install
npm run dev
```

Abrir la URL local que muestra Vite.

## Producción

```sh
npm run build
npm run preview
```

El resultado se genera en `dist/`. Los textos y secciones están en `src/App.jsx`, los estilos en `src/styles.css` y los logos en `public/assets/`.
